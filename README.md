# FoodFlow

FoodFlow is a restaurant management and direct ordering platform for restaurants, cafes, bakeries and cloud kitchens.

## Main Goal

Help restaurants manage orders, menus, customers, billing, kitchen operations and business analytics from one platform.

## Technology Stack

### Frontend
- React
- TypeScript

### Backend
- Java 17
- Spring Boot

### Planned Database
- PostgreSQL

## Future Features

- Restaurant Website
- QR Menu
- Table Management
- Online Ordering
- Kitchen Display System
- Billing
- Inventory
- Customer CRM
- Loyalty Program
- Payments
- Multi-Branch Management
- Analytics
- AI Features
